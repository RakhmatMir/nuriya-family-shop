# Nuriya Family Shop — сайт-витрина

Сайт магазина детской одежды на вес (Фергана, Ватный, рядом с «Мерос»).
Источники: Telegram @savdo_sotiq_mustafo_shop, @kiloli_tavar, Instagram @nuriya__family__shop.

## Как открыть
Двойной клик по `index.html` — откроется в браузере. Сервер не нужен.

## Что внутри
| Файл / папка | Что это |
|---|---|
| `index.html` | Главная: первый экран, «как купить на вес», каталог с разделами, адрес и контакты |
| `product.html?id=...` | Карточка товара: галерея фото, цены за кг, выбор веса, описание, «В корзину» |
| `cart.html` | Корзина: вес по каждому товару, итог, автоматически оптовая цена от 5 кг |
| `js/products.js` | **Все товары, цены и контакты** — менять здесь |
| `js/app.js` | Тексты на узбекском и русском, корзина, шапка и подвал |
| `css/style.css` | Оформление (цвета — в начале файла) |
| `img/` | Фото товаров: `<id товара>-1.jpg`, `-2.jpg` … |

## Как добавить товар
1. Положить фото в `img/` с именами `новый-id-1.jpg`, `новый-id-2.jpg`.
2. В `js/products.js` скопировать любой блок товара, поменять `id`, `cat`, `photos` (сколько фото) и тексты `uz` / `ru`.

## Важно
- Цены (210 000 сум/кг в розницу, 190 000 сум/кг опт от 5 кг) взяты из старого сообщения в @kiloli_tavar — **уточнить у владельца**.
- В обычном браузере кнопка «Оформить заказ» ведёт в Telegram к админу @Dili5000. Внутри Telegram-бота заказ отправляется админу автоматически (см. ниже).
- Фото взяты из Telegram-группы магазина (ноябрь 2026). Фото с чужими логотипами брендов и китайскими ценниками не использовались.

## Анимации (с 08.11.2026)
- Первый экран собирается по словам, блоки и карточки плавно появляются при прокрутке, фото товара «летит» в корзину, на телефоне фото листаются пальцем, переходы между страницами плавные (Chrome/Edge, при открытии через сервер).
- Если в Windows выключены «Эффекты анимации», сайт сам включает спокойный режим: только мягкие появления без движения. Посмотреть полную версию можно, добавив к адресу `?motion=full`.
- После правок CSS/JS увеличивайте номер `?v=7` в подключении файлов в трёх HTML — иначе браузер может показать старую версию.

## Telegram-бот и Mini App (с 10.11.2026)
Тот же сайт открывается внутри Telegram. Покупатель жмёт в боте кнопку **«🛍 Do'kon / Магазин»** внизу чата → выбирает вещи → в корзине вводит имя и телефон → **«Отправить заказ»**. Бот сам пересчитывает сумму по ценам из `js/products.js` и присылает заказ админу, а покупателю отвечает «заказ принят».

| Файл | Что это |
|---|---|
| `bot/main.py` | Бот: кнопка магазина, приём заказа, отправка админу |
| `bot/orders.py` | Чтение каталога с сайта и расчёт суммы |
| `bot/.env.example` | Образец настроек (токен, кому слать заказы) |
| `bot/deploy.sh` | Обновить бота на сервере: `bash bot/deploy.sh` |

- Бот работает на сервере Burger Street: папка `/opt/projects/nuriya-shop-bot`, служба `nuriya-shop-bot` (`journalctl -u nuriya-shop-bot -f` — журнал).
- Токен лежит только на сервере в `/opt/projects/nuriya-shop-bot/.env`, в git не попадает.
- **Админ (@Dili5000) должен один раз открыть бота и нажать «Start»** — иначе бот не сможет ему писать (так устроен Telegram). Кому слать заказы — строка `ADMIN_USERNAMES` в `.env`.
- Заказ отправляется только через кнопку внизу чата. Не ставьте сайт на кнопку «Меню» в @BotFather — оттуда отправка заказа не работает.
- Цены и товары бот берёт с опубликованного сайта, поэтому после правки `js/products.js` достаточно опубликовать сайт.
